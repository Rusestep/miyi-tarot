# Rider–Waite–Smith Tarot images

- Deck: Rider–Waite–Smith Tarot (78 cards)
- Artist: Pamela Colman Smith
- Year: 1909–1910
- Source archive: https://github.com/metabismuth/tarot-json/releases/tag/v0
- Original image source noted by the archive: http://data.totl.net/tarot-rwcs-images/
- Reference/license verification: https://commons.wikimedia.org/wiki/Category:Rider-Waite-Smith_tarot_deck_(TaionWC)
- Status: Original Rider–Waite–Smith artwork is Public Domain
- Downloaded: 2026-08-02

The source archive contains 78 individual 350 × 600 JPEG scans. They were resized to 300 × 514 WebP files at quality 75 for faster private web use. The matching Wikimedia “Pam-A” set was checked through the MediaWiki API; its file metadata reports Public Domain and does not require attribution.
